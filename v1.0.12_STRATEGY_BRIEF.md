### Project: FileIT Učebna UX Redesign — Phase 1
**Objective:** Help users manually classify unrecognized documents with minimal cognitive load. Surface key context clues (filename, folder origin, confidence score) so users can make informed choices quickly.

**Target Users:** Czech financial advisors classifying client document archives. Files are often named opaquely; folder structure is the only reliable hint.

**Success Metrics:**
- Users can classify a file in <10 seconds (vs ~30s currently)
- Confidence in their choice (reduced second-guessing)
- Fewer requests for "I'm not sure which institution this is"

**Current State (v1.0.11):**
- Card grid showing pattern clusters
- Clickable to expand → shows thumbnails, color swatches, signal pills
- BUT: No filename context, no origin hint, no confidence indicator
- User has to guess from thumbnails alone

**Desired State (Phase 1):**
- Each unrecognized file shown as a list card (not grid)
- Card headers show:
  - Original filename (masked format: `[BANK]_2024_statement_01.pdf` → show this)
  - Folder origin: `📁 C:\Downloads\Air Bank\2024`
- Confidence badges: Color-coded percentages (🟢 87%, 🟡 52%, 🔴 18%)
- Signal pills underneath: show which patterns matched (keyword, logo, text, color)
- Hover effect: background tint, "click to preview"
- Click → opens side panel with file preview + institution picker

**Design Constraints:**
- **Compliance:** No PII in filenames (use masked format if needed)
- **Speed:** Users need to see context in <2 seconds
- **Mobile-friendly:** Should work on tablets (financial advisors use laptops, but consider responsive design)

**Design Deliverables Needed:**
1. **List card mockup** — single unrecognized file card showing filename + origin + confidence + signals
2. **Preview panel mockup** — side panel opening on click, showing file preview + "Which institution?" picker
3. **Micro-interaction spec** — hover states, click feedback, loading states
4. **Confidence color logic** — when to show green (high), yellow (medium), red (low) badges

**Reference:** Neon Twilight color system (indigo, deep pink, coral). Use for badges and accents.

**Phase 2 (next sprint):** "Learn this pattern" workflow — after user classifies a file, ask what signal was strongest, then batch-rescan similar files.
